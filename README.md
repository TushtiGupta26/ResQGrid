# 🚨 ResQGrid

### *Find. Connect. Reunite.*

**ResQGrid** is a community-powered, real-time emergency response platform connecting **citizens, guardians, volunteers, NGOs, hospitals, and authorities** through one coordinated system.

It replaces fragmented communication across social media, messaging apps, phone calls, and separate portals with a centralized platform for **emergency reporting, volunteer coordination, missing-person searches, verified sightings, and real-time monitoring.**

---

## Problem

Emergency response is often scattered across multiple platforms, resulting in:

* Delayed response
* Duplicate search efforts
* Poor volunteer coordination
* Lost or outdated information
* Unstructured missing-person searches
* Limited visibility into rescue operations

### Our Solution

ResQGrid provides a unified system to:

* Report emergencies
*  Notify nearby volunteers
*  Organize searches using grids
*  Prioritize search areas using AI
*  Track volunteers in real time
*  Report and verify sightings
*  Communicate with responders
*  Monitor emergency operations

> **Get the right information to the right people at the right place and time.**

## ⭐ Key Features

### 📍 Geo-Fenced Alerts

Notifies nearby available volunteers based on **location, distance, availability, and emergency priority**.

### 🗺️ Grid-Based Search

Divides search areas into grids so volunteers can claim, search, and update specific regions, reducing duplicate work.

### 🤖 AI-Assisted Prioritization

AI analyzes factors such as **distance, time elapsed, verified sightings, population density, and environmental conditions** to recommend priority search areas.

### 📡 Live Tracking

Coordinators can monitor volunteer locations, claimed grids, search coverage, and emergency status.

### 📸 Verified Sightings

Volunteers can submit **photos, videos, GPS locations, descriptions, and confidence levels** for verification.

### 💬 Real-Time Communication

Supports messaging, group communication, emergency broadcasts, notifications, and live updates using **Socket.IO**.

### 🏆 Volunteer Gamification

Volunteers earn **XP, levels, badges, and leaderboard rankings** for contributing to emergency operations.
